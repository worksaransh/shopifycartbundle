## Checks that came back clean (with how)

- No REST Admin API, Scripts or ScriptTag usage (grep); GraphQL only; one `ApiVersion` constant.
- No price is sent from the browser: storefront posts variant id, quantity and properties only (grep + tests). The Function reads
  prices from the cart. Forged `_bundle_id` / `_upsell_id` get no discount and no attribution (tests).
- Every Prisma query on a shop-owned table is scoped by `shopId` (`tests/tenant-scope.test.ts`, AST-based).
- No log line carries tokens or customer data (grep; redaction test). Webhook payloads are never logged.
- Webhooks: HMAC on all 7 routes (tests), idempotent (receipts + natural keys), refunds reduce revenue, duplicates do not double count.
- Function: fails open; loops bounded by lines x rules; 100-line cart test; tier boundaries and incomplete bundles tested.
- Storefront: 13.8 KB gzipped JS total (guard in CI); async/deferred via theme extension; space reserved for the bar; reduced motion respected; aria-live on every status; generic selector fallback.
- Scope creep: none beyond the four v1 features (plus ops endpoints `/healthz` and `/api/jobs/reconcile`). All four scopes are used
  (`read_products` collection lookups, `write_products` product metafields, `read_orders` webhooks, `write_discounts` the node).

| #   | Incident                                                      | Alert                                                                                                                                    |

| 4   | Theme change breaks the cart adapter                          | Rising `cart_surface_missing` events per shop                                                                                            |
| 5   | Webhook failures (app down, DB errors)                        | Shopify Partner dashboard webhook failure rate + app 5xx on `/webhooks/*`                                                                |
| 6   | Database unavailable or pool exhausted                        | Uptime monitor on `/healthz` (503)                                                                                                       |
| 7   | Access-token refresh failure (expiring offline tokens)        | Sync failures with HTTP 401 in logs                                                                                                      |
| 8   | Stacking complaint with a merchant discount code              | Support-ticket tag + the synthetic in #1 run with a code applied                                                                         |
| 9   | Attribution silently wrong (payload shape change)             | Consistency check: shops with `bundle_added` events but zero touched orders for 7 days                                                   |

Error tracking, the uptime monitor and these alerts are **not set up** (they need accounts); only `/healthz` and `/api/jobs/reconcile` exist.
